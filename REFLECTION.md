# Reflection

*What did you ask Copilot to help you build? How did you break down the problem?*

I asked Copilot to help me build a personal planner. I broke it down into three parts: structure, functionality, and styling. I started with the basic layout, then worked on making the features function properly before focusing on the appearance.

*How did your approach to asking questions change as you worked?*

I started working more slowly and thinking carefully about what I wanted to build. I found it easier to visualize what I wanted first, make it work, and then focus on the styling. I also became more specific with my instructions and told Copilot to only make the changes I requested.

*What parts of the development process with GitHub Copilot surprised you?*

I was surprised by how quickly Copilot could make changes to my code. I could ask it to add or remove features, and it could update multiple files. I also learned that I needed to be specific because sometimes it made changes I didn't ask for.

*What did you learn about the technology you used that you didn't know before?*

I learned more about how HTML, CSS, and JavaScript work together to create a website. I also learned that JavaScript can save tasks in local storage, allowing them to remain saved even after refreshing the page.

*What would you do differently if you had to build this again?*

I would spend more time planning the design and features before starting. I would also make smaller changes and test them as I went. This would help me avoid unnecessary changes and keep the project closer to what I originally wanted.
